# Brain Lab

Brain Lab is an Android-first cognitive assessment and brain-training app. It combines practice activities for memory, attention, reasoning, spatial skills, and creative thinking with a local progress profile.

## Project status

Initial project setup is being built. The first milestone is an offline-friendly Expo / React Native app with interactive mini-games, a practice assessment, local score history, and clear limits around IQ claims.

## Principles

- Training scores describe performance on these activities; they are not a clinical diagnosis or an official IQ score.
- Keep the first release usable without an account or paid backend.
- Preserve user progress locally on the device.
- Test and verify builds before describing an APK as ready.

## Planned Android build

The project will use Expo and EAS Build. A real installable APK must be produced and tested before it can be considered release-ready.
